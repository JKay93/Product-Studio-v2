# Design discipline

Follow the selected project's approved journeys, content, components, tokens,
responsive behavior and accessibility when available. Another project's design
never becomes this project's rule.
Before UI implementation, resolve missing experience choices through Designer's
focused chat advice. A new component needs an unmet requirement.
Review rendered results at relevant sizes and states. Preserve approved content
and navigation; do not introduce unsolicited visual changes or design documents.
Designer returns concise decisions, necessary states and actionable checks.
No third-party design skill is selected by this setup.
