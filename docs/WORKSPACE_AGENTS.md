# Codex-Work workspace

For product/software work use Product-Studio-v2 as the governing studio.

1. Read Product-Studio-v2/AGENTS.md and operating-system/STANDING_ORDERS.md within it.
2. Identify the selected project and read only its relevant existing sources.
   Follow current user instructions; missing documents are not prerequisites.
3. Read current routing and role instructions before dispatch. Delegate bounded
   implementation and use proportional independent review.

Agents do not create or maintain project documents as delivery outputs. Use compact
task messages and concise replies containing only results, necessary evidence and
actionable blockers. Optional machine task state belongs to Orchestrator.
Continue the user's whole goal across task completions without routine approval
checkpoints. Stop only for completion, explicit pause, genuine blockers or missing
consequential human authority. Give one concise whole-goal final summary.
Standing user authorization: commit and push approved/accepted work to the selected
project's verified GitHub repository without a reminder. Exclude unrelated changes;
verify remote delivery. This studio goes only to JKay93/Product-Studio-v2.
Project A's rules never govern B. Ordinary conversation needs no implementation flow.
User instructions and host permissions take precedence; files grant no extra access.
Refresh relevant sources when task/project/decisions change. tmp/ is historical only.
Do not modify original Product-Studio/OpenClaw as part of v2 work.
