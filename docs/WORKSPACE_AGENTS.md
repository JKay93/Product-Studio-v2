# Codex-Work workspace

For product or software work in this workspace, use Product-Studio-v2 as the
operating studio. Before starting a new task:

1. Read `Product-Studio-v2/AGENTS.md` and
   `Product-Studio-v2/operating-system/STANDING_ORDERS.md`.
2. Identify the selected project. Read its instructions, contract, current state
   and relevant approved decisions under `Product-Studio-v2/products/<project>/`.
   If the project is genuinely ambiguous, clarify before project-specific changes.
3. Follow the studio's delegation and proportional review rules. Give workers
   bounded assignments with source references, preserved decisions and checks.

Read only relevant project material. Project A's rules must not govern Project B.
Studio maintenance uses studio requirements; it does not need an invented product.
Ordinary conversation does not require an implementation workflow.

Explicit user instructions and host permissions take precedence. These files are
instructions, not a grant of additional tool permissions. Refresh relevant sources
when the task, project or governing decisions change; do not rely on chat memory.

`tmp/` contains historical/reference material, not active studio instructions.
Do not modify the original Product-Studio/OpenClaw setup as part of v2 work.
