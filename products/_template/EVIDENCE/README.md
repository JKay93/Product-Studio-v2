# Evidence

Keep relevant check output, review findings and visual evidence here. Record the task,
candidate revision and requirement/contract revision assessed. Evidence is not current
after relevant inputs change. Do not store secrets, whole transcripts or private reasoning.

Use the shared [verification and release report](../../../operating-system/templates/verification-release-report.md)
when a candidate needs a durable acceptance and delivery summary. The reviewer supplies
verification findings, the orchestrator records acceptance, and independent review
findings remain separate.
