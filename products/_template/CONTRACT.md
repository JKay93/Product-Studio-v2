# Product contract

## Problem, users and outcome
To be defined with the user.

## Scope and exclusions
Record approved MVP boundaries and core journeys.

## Authority
Record user approval and its source. Identify application repository and local path.
Specify financial allowance, push/merge permissions and release authority. Defaults:
no new external spending, sensitive access changes or production publication.

## Acceptance
Define observable outcomes and required verification. Do not invent approval.
