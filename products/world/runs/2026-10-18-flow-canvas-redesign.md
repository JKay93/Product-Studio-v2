## Integration research

n8n separates service-specific action/trigger nodes from reusable core logic and generic API nodes. One app can expose several operations, so apps, nodes, operations and credential types should not be conflated into a catalogue count. [Official node types](https://docs.n8n.io/integrations/builtin/node-types).

Its common node framework supplies parameter fields, operation selection and request routing. Current docs recommend declarative definitions for ordinary REST actions, with programmatic nodes for triggers, non-REST protocols or exceptional transformations. This reduces repeated UI/request code while each provider API still needs maintenance. [Building styles](https://docs.n8n.io/connect/create-nodes/plan-your-node/choose-a-node-building-style.md).

Credential definitions specify fields, authentication and connection tests; encrypted credential storage and reuse avoid building authentication independently for every operation. HTTP Request can reuse predefined credentials to cover endpoints lacking a dedicated operation, while Webhook covers incoming API events. Neither bypasses provider permission, app verification or merchant setup. [Credentials](https://docs.n8n.io/connect/create-nodes/build-your-node/reference/credentials-files.md), [HTTP Request](https://docs.n8n.io/integrations/builtin/core-nodes/n8n-nodes-base.httprequest), [Webhook](https://docs.n8n.io/integrations/builtin/core-nodes/n8n-nodes-base.webhook).

The ecosystem contributes npm-distributed community nodes. Verified packages can appear in the picker; unverified installation has self-hosting limits. n8n explicitly warns that community code can access host resources and workflow data. A marketplace is therefore also a review/versioning/provenance/support obligation. [Publishing](https://docs.n8n.io/connect/create-nodes/deploy-your-node/submit-community-nodes.md), [Verification](https://docs.n8n.io/connect/create-nodes/build-your-node/reference/verification-guidelines.md), [Risks](https://docs.n8n.io/integrations/community-nodes/risks). Managed OAuth convenience also depends on platform-owned provider apps; listed Google nodes on Cloud have simplified OAuth, while self-hosted setup needs its own client/app. [Google OAuth](https://docs.n8n.io/integrations/builtin/credentials/google/oauth-single-service).
