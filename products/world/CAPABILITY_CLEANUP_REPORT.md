## Audit coverage and cleanup

Missing or deliberately deferred capabilities include production deployment/operations, real backup and key-custody rehearsal, completed live connector onboarding/delivery, InvoiceNow transmission, automatic Google token refresh, WhatsApp template sends, OCR/broad office-file ingestion and the new human-invitation experience. These are gaps or separate product decisions, not features silently implemented by this cleanup. The positive live Agent-built Flow saved-draft check is a verification gap rather than proof that its underlying authoring capability is absent.

The tracked inventory contains 973 files, including 339 application source files at baseline. The scan covered source/import/export relationships, package and manual/dynamic entrypoints, test/build wiring and the existing capability/verification records. Source inspection was concentrated on responsibility boundaries and suspect unused code; this is not a claim that every historical fixture/document was manually reviewed line by line.

Removed two unreferenced UI modules: `src/ui/shell/context-divider.tsx` (60 lines) and `use-context-width.ts` (50 lines), plus the obsolete selector and design-manifest entry. Current workspace behaviour already expects that divider to be absent. Historical browser evidence/scripts remain retained.

Removed seven repository-wide unreferenced declarations: `commerceJson`, `businessPilotInput`, `collaborationLimits`, `sessionDiscussionLimits`, `memoryContractVersion`, `defaultGuestDuration` and `InternalTaskDecisionReceipt`, and their orphan imports. Enforced runtime/SQL limits and actual task-decision records remain unchanged; these were unused duplicate/helper declarations. Removing `businessPilotInput` also removes its unused eager fixture construction.

Net source reduction is 130 lines and 3,314 LF-normalised bytes across affected source; five focused modules were added and two dead modules removed. This is maintainability work, not a large bundle-size or latency optimisation. Splits preserve original declarations/logic; import/re-export glue can slightly increase local line counts. No model prompt/context shortening, guidance changes, permissions changes, dependencies or SQL changes were made.

Retained intentionally: the 1,177-line persistent workspace lifecycle and other tightly coupled stateful compositions; supported mock adapters; framework-discovered routes/stories; dynamically spawned PDF parser; peer dependencies such as y-protocols; manual startup/recovery/evaluation tools; immutable migrations and historical fixtures. File length alone does not prove bloat or justify a risky rewrite. Larger composition/state separation is a useful future design-driven task, not silently marked complete here.
