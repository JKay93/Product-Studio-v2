# Architecture

This directory holds shared technical records that apply across multiple approved
features: system context, interfaces, data contracts, security boundaries, decision
trade-offs and verification guidance.

No application architecture or technology stack has been selected. Add substantive
technical designs only after product requirements exist and a Technical Specialist
has a bounded architecture assignment. The builder implements an agreed design; a
separate reviewer checks the resulting candidate.

Project-wide module rules are in [MODULARITY.md](MODULARITY.md). Feature-specific
technical notes belong with the feature under `../features/<domain>/<feature>/` once
that path is backed by approved scope.
