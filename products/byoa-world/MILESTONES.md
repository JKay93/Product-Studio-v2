# Milestones

These milestones are sequencing placeholders. They do not approve product scope.

1. **Foundation** — project organization authored, validated and independently
   reviewed.
2. **Product definition** — authoritative handoff material digested; problem, users,
   journeys, requirements and exclusions approved.
3. **Technical and design definition** — architecture, interfaces, security
   boundaries and design conventions agreed for approved scope.
4. **Implementation** — bounded feature work delegated to builders with relevant
   independent review.
5. **Delivery** — acceptance, repository actions and release performed only under
   recorded authority.

Only the Foundation milestone is currently authorized.
