# Features

Future approved feature material belongs at:

```text
features/<domain>/<feature>/
```

The placeholders describe a path convention only. No domain or feature is approved
or implied. Create a concrete path after an authoritative requirement or approved
decision names its ownership and scope.

A feature directory may later contain its requirements, design notes, technical
notes, acceptance criteria and evidence links. Keep cross-feature contracts and
shared conventions in `../architecture/` or `../design-system/` as appropriate.
