## Rationale and consequences

The first useful journey is create a project World → write a note → save → reopen,
including after restart and alongside a second World. A separate startup/database
keeps this human foundation independent of historical Session/pilot composition.
React organizes editor/dialog state; SQLite provides transactional revisions and
constraints. Native JavaScript/JSON/cloud alternatives remain recorded in the plan,
not selected. Built-in SQLite RC maturity, short synchronous transactions, local
demo identity and lack of unsaved-crash recovery are accepted limits.

import or original evidence rewrite. Before edits, orchestrator captured and verified
